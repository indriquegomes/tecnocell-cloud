# TecnoCell Cloud — instruções

As regras do projeto estão em **um lugar só**:

1. Leia `AGENTS.md` (raiz do repositório) inteiro antes de qualquer tarefa.
2. Vale tudo o que está lá: autorização, dado real, trava de deploy, UTF-8,
   ponytail, verificação, armadilhas, regras de negócio, papéis dos agentes.
3. Não crie regra nova aqui. Regra nova vai para o `AGENTS.md`.

Para o "onde mora cada informação" (mapa, glossário, passagem de turno,
receitas, registros) veja a seção 12 do `AGENTS.md`.
